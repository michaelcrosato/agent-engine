# Content kinds (generated)

Data file schemas, generated by `npm run check`. Do not edit.

## room — data/rooms/<id>.json

A playable space: grid text-map, placed prefabs, look, music, and tuning.

```
doc       string = "" — What this room demonstrates or is for
look      look id = "default" — Look id (lighting, sky, materials, post)
music     music id = "" — Song id, or empty for silence
tuning    string[] = [] — Extra tuning presets for this room
grid      object — Text-map layout (walls, floors, glyph prefabs)
entities  object[] = []
```

## prefab — data/prefabs/<id>.json

Entity template: components (by name) with field values, tags, and an optional parent.

```
doc         string = "" — What this prefab is, one line
extends     prefab id = "" — Parent prefab id; components merge field by field
tags        string[] = [] — Tags added to every instance
components  object = {} — Component name → fields
```

## tuning — data/tuning/<id>.json

Preset of component overrides by prefab or tag; switch game feel without editing prefabs.

```
doc      string = ""
prefabs  object = {} — Prefab id → component overrides (also applies to prefabs that extend it)
tags     object = {} — Tag → component overrides
```

## input — data/input/<id>.json

Input map: named actions bound to keys, mouse buttons, and gamepad controls.

```
doc      string = ""
actions  object — Action → list of bindings
mouse    object = {}
gamepad  object = {}
```

## clip — data/clips/<id>.json

Animation clip: keyframe or procedural sine tracks that offset puppet parts.

```
doc       string = ""
duration  number = 1
loop      boolean = true
tracks    object[]
```

## sound — data/sounds/<id>.json

Sound patch: layered synth voices (waves, envelopes, pitch glides, filters) plus fx.

```
doc             string = ""
gain            number = 0.8 [0..4]
layers          object[]
fx              object = {}
pitchVariation  number = 0 [0..1] — Random pitch ± fraction per play
gainVariation   number = 0 [0..1] — Random volume ± fraction per play
bus             "sfx"|"ui"|"music"|"voice" = "sfx"
maxVoices       integer = 6 [1..32] — Oldest instance stops beyond this
```

## music — data/music/<id>.json

Looping song: tempo, key, chord progression, and step-sequenced tracks of synth instruments.

```
doc          string = ""
bpm          number = 110 [30..300]
bars         integer = 8 [1..128]
beatsPerBar  integer = 4 [1..16]
stepsPerBar  integer = 16 [1..64]
swing        number = 0 [0..0.5] — Delay of off-beat steps (fraction of a step)
key          "C"|"C#"|"Db"|"D"|"D#"|"Eb"|"E"|"F"|"F#"|"Gb"|"G"|"G#"|"Ab"|"A"|"A#"|"Bb"|"B" = "A"
scale        "major"|"minor"|"dorian"|"phrygian"|"lydian"|"mixolydian"|"harmonicMinor"|"pentatonic"|"minorPentatonic"|"blues" = "minor"
chords       string[] = ["i"] — Roman numerals per bar, cycled: ["i","VI","III","VII"]
instruments  object — Name → sound id or inline patch. Pitched instruments are tuned so freq 440 = the note.
tracks       object[]
gain         number = 0.7 [0..4]
reverb       number = 0.15 [0..1]
```

## puppet — data/puppets/<id>.json

Procedural model: a tree of primitive parts with materials; animated by clips.

```
doc    string = ""
parts  object[] — Primitive parts; parents must come first
clips  object = {} — Animation role → clip id, e.g. { "idle": "grunt-idle", "walk": "grunt-walk" }
```

## look — data/looks/<id>.json

Scene style: sky, fog, lighting, exposure, post-processing, and the named material palette.

```
doc          string = ""
extends      look id = "" — Parent look id; fields and materials merge
sky          object = {}
fog          object = {}
ambient      object = {}
sun          object = {}
exposure     number = 1
toneMapping  "aces"|"agx"|"neutral"|"none" = "agx"
renderScale  number = 1 [0.1..2] — <1 renders at lower resolution (retro)
post         post id = "" — Post-processing stack id (data/post), "" for none
materials    object = {} — Material name → material. Parts refer to names: wall, floor, metal, glow, ...
```

## post — data/post/<id>.json

Post-processing stack: ordered passes (bloom, vignette, grade, grain, pixelate, ...).

```
doc     string = ""
passes  any[] = [] — Applied in order after the scene renders
```

## texture — data/textures/<id>.json

Procedural texture recipe: ordered ops (bricks, noise, planks, ...) → albedo, normal, roughness.

```
doc        string = ""
size       integer = 256 — Pixels per side (power of two). 32-64 for pixel-art looks
seed       integer = 1
roughness  number = 0.8 [0..1] — Base roughness before layers
normal     number = 2 [0..16] — Normal-map strength from height (0 = none)
layers     any[] — Ops applied in order: { "op": "bricks", ... }
```

## effect — data/effects/<id>.json

Particle burst or tracer with optional flash light and sound.

```
doc       string = ""
type      "burst"|"tracer" = "burst" — burst = particles; tracer = fading line
count     integer = 12 [0..512]
lifetime  any[] = [0.2,0.5] — [min, max] seconds
speed     any[] = [2,6] — [min, max] m/s
spread    number = 70 [0..180] — Cone half-angle around the normal (180 = sphere)
size      any[] = [0.04,0.08] — [min, max] meters
sizeEnd   number = 0.2 [0..] — Size multiplier at end of life
color     string = "#ffd27a"
colorEnd  string = "#ff5a1f"
gravity   number = -9
drag      number = 1 [0..]
radius    number = 0 [0..] — Spawn volume radius
glow      boolean = true — Additive blending (fire, sparks); false for smoke/debris
light     object — Brief flash light
sound     sound id = "" — Sound played at the effect
width     number = 0.02 [0..] — tracer: line width hint
```
