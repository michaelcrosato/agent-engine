# Endless content and systemic combat

Rift Runner treats a level as a sentence assembled from independently seeded slots:

`seed + depth → biome + layout + mechanics + chassis + behavior + element + modifier + boss sequence`

The generic `ContentGrammar` selects weighted compatible tokens. `tags`, `requires` and `excludes`
let new tokens express compatibility. Each slot has an independent seed: adding scenery does not
change the biome or monster roll. An unsatisfiable slot throws an actionable `EngineError`.

## The content vocabulary

`games/rift-runner/data/expeditions/core.json` is the validated vocabulary. Its JSON Schema and
reference docs are generated by `npm run check`.

| Vocabulary | Role |
| --- | --- |
| `lessons` | Ordered mechanic IDs, names and a one-line player hint |
| `biomes` | Look asset, accent color and ground material |
| `layouts` | Named arena modules with terrace sockets `[x,z]` |
| `chassis` | Puppet prefab, health, speed and initial behavior |
| `bosses` | Boss chassis, health and composable `shot`, `strike`, `nova` sequences |
| `affixes` | Named stat contributions and roll ranges |

Puppets and clips are ordinary engine assets; body geometry and animation are separate from
behavior. The three monster bodies can use four behaviors, four elements and five modifier states.
Biome and layout tags feed monster composition, and data tokens accept weights and compatibility
constraints. Bosses reuse the same damage, elemental, projectile and telegraph rules. They gain faster attack
cycles below half health. Telegraphed strikes commit to a position before damage is resolved.

Skill nodes are separate JSON assets under `data/skills`. Each node names a branch, prerequisite,
rank count and stat contributions. Equipment and skills feed one build calculation.

To add a theme, add a look that extends `haven` and append a biome token. To add an arena layout,
append terrace sockets, keeping the central north/south route clear and the starting camera space
open. To add a monster, create a puppet/prefab and append a chassis. To add a boss sequence,
compose the existing pattern words in `bosses`. These edits need no new combat-system code.
A genuinely new behavior or mechanic is a small game system plus a new schema enum and tests.

## The eight lessons

| Depth | Level | Optional advantage |
| --- | --- | --- |
| 1 | Slipstream Steps | Launch pads reset the air jump and create high routes |
| 2 | Chain Reaction | Shootable reactors ignite clustered enemies |
| 3 | Conductive Basin | Wet targets conduct shock to nearby opponents |
| 4 | Frostwake | Frost fields slow actors and enable thermal fracture |
| 5 | Overdrive Circuit | Pylons temporarily empower damage and dash recovery |
| 6 | Gravity Well | Wells pull enemies into area attacks |
| 7 | Echo Forge | Pads accelerate ability recovery |
| 8 | Phase Lanes | Linked gates blink the runner across the arena |

Exactly one new environment tool appears at each authored depth. Later lessons can reuse earlier
tools. After depth eight, two to four known mechanics are recombined, alongside layouts, palettes,
enemies and boss sequences. The central combat route stays on solid ground; no mechanic is a key,
puzzle or completion prerequisite. All hostiles must be defeated to clear a level.

## Shared interaction rules

| Combination | Result |
| --- | --- |
| Fire hit | Three-second burn attributed to its owner |
| Frost hit | Movement slow |
| Fire on chilled / frost on burning | Thermal fracture, damaging nearby opponents |
| Shock on wet | Up to three extra chained targets |
| Shock + relay affixes/skills | Additional chain targets, up to eight |
| Vortex + charge / nova / death blast | Pulled targets share an area attack |
| Echo + cooldown build | Frequent complementary elemental abilities |
| Overdrive + movement + a fast weapon | Mobile burst-damage route |

Secondary damage is already scaled and cannot crit, leech or initiate another reaction.
This prevents recursive proc explosions while preserving deliberate combinations. Area attacks
respect world cover. All damaging boss attacks have a visible windup or travel time.

## Scaling and limits

There is no authored final level. Depth scales item power and enemy health linearly; damage,
rarity and composition add separate growth. Abilities scale with gear. XP thresholds use a
quadratic curve and a closed-form sum with binary search, so a large reward never loops through
millions of levels. Mastery continues after the finite tree.

This is an endless sequence, not an infinitely large in-memory world. Each arena uses at most
22 active monsters and 21 spawn tickets per wave, with two or three waves. Old rooms and their
drops are destroyed. Inventory holds 40 items, damage feedback 48 entries, and the save retains
100 recent depth records. Particles use the engine pools. Dynamic palette changes rebuild only
the current room's materials.

Depths and counters use JavaScript safe integers; "endless" means no designed endpoint within
that finite representation. Extremely deep content is covered by finite-state and deterministic
seed tests, including the maximum supported depth. This is a single-player local game; multiplayer,
account sync and a server economy are outside this implementation.
